# Public metadata

This directory documents the anonymous rating files and the analysis samples.

`data_dictionary.csv` defines every released field. `sample_flow.csv` records the
137-teacher analysis snapshot, 121 complete quality records, the 75-teacher
practitioner-referenced evaluation, the 62-teacher matched comparison, and the
four-expert paired-round design. `delphi_round_metadata.csv` documents the expert
score sets and arithmetic-average rule. `analysis_reconciliation.csv` records the
final public counts and the source-checked correction applied before release.

The metadata contain no collection-mode field, original identifier, name, contact
detail, school, student narrative, device/location value, screenshot link, or
deployment secret.
