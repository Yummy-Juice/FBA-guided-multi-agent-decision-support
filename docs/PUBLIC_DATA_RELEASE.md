# Public data release

The authors designated the anonymous teacher and expert rating matrices in this
package for public release. Each file contains standardized record numbers and
six-dimension numeric ratings. The public teacher table excludes collection mode,
source identifiers, names, teaching stage, grade, and other source metadata.

The release includes:

- 137 anonymous teacher records numbered `P001` through `P137`;
- 75 distinct teachers in the practitioner-referenced similarity evaluation;
- 62 teachers in the matched general-purpose-AI comparison;
- four anonymous experts, two paired rounds, and the four arithmetic-average
  final expert records;
- analysis code, generated aggregate results, the sanitized workflow blueprint,
  and ethics approval certificate `BNU202601050010`.

The original source workbooks, identity fields, free-text material, screenshots,
private workflow export, credentials, signed links, and retrieval corpus remain
outside the public package.
