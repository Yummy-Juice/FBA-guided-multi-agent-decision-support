# Public release manifest

This directory is the complete public reproducibility package.

## Included

- `data/public_ratings/`: anonymous teacher and expert rating matrices;
- `data/public_metadata/`: field definitions, sample flow, expert-round metadata,
  and reconciliation notes;
- `code/`: validation, analysis, plotting, and supplementary-table scripts;
- `results/`: generated aggregate tables, figures, and run metadata;
- `workflow/`: sanitized agent workflow and its documentation;
- `docs/ethics/ethics_approval_BNU202601050010.pdf`: ethics approval certificate;
- `docs/`: release, deidentification, source, and analysis documentation.

## Privacy boundary

The public files use newly assigned teacher numbers `P001` through `P137` and
expert numbers `E001` through `E004`. Collection mode, original identifiers,
names, teaching stage, grade, contact details, device/location metadata,
screenshots, narratives, chat logs, school identifiers, credentials, and signed
links are outside the release.

## Evidence scope

The package supports reproducibility of teacher-perception and expert-rating
analyses. Clinical validity, student outcomes, and intervention effectiveness are
separate research questions.
